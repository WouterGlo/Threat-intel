# Threat-intel

A personal threat intelligence platform that collects CVEs from the NVD and
CISA KEV catalogue, prioritises them using evidence, and explains them clearly.

**Status:** Early development (Phase 1: planning and threat model)

## Goals
- Learn secure C#/.NET development and DevSecOps practices
- Build a portfolio-quality, security-first application

## Disclaimer
Personal learning project. Uses public data only.
